# 🏠 Rental Point

A verified rental, roommate & sublet discovery platform for Bangladesh — built to replace the chaos of unmoderated Facebook housing groups with a structured, purpose-built alternative.

> Web Technologies (CSC 3222) — Group Project

---

## 📖 About

Finding rental housing, roommates, or short-term sublets in Bangladesh's major cities is still handled informally — mostly through Facebook groups and word-of-mouth. These channels lack structured search, owner verification, and any real accountability, leaving listings duplicated, outdated, or outright fraudulent.

**Rental Point** consolidates property rentals, roommate matching, and sublet listings into one platform, with owner verification, a booking request system, and content moderation — so users get the searchability of a real platform without losing the simplicity people are already used to.

---

## 👥 User Roles

| Role | Description |
|---|---|
| **Tenant** | Finds properties, posts Roommate Wanted / Sublet listings, sends booking requests |
| **Property Owner** | Lists verified rental properties, manages bookings and availability |
| **Admin** | Verifies owners, moderates content, handles support tickets |

---

## ✨ Features

### Common (All Users)
- Login / Logout / Registration
- Change or reset password
- Manage profile (view, edit, delete)
- Personalized dashboard
- Browse & search listings with filters (area, price, post type)
- Save posts, report inappropriate posts/users
- Submit and track help/support tickets

### Tenant
- **Roommate/Sublet Listing Management** — create, edit, delete own posts
- **Contact & Booking** — send booking requests, track status, view owner contact info
- **Rental Profile & Preferences** — budget, preferred area, move-in date, and lifestyle criteria shown on profile

### Property Owner
- **Rental Listing Management** — create, edit, delete, mark filled, view performance stats (views/saves/contacts)
- **Booking & Availability Management** — set availability, approve/reject booking requests
- **Owner Verification** — upload ownership documents, display verified badge once approved

### Admin
- **User & Content Moderation** — remove users, review reports, remove reported posts
- **Verification Management** — review, approve, or reject owner documents
- **Support Management** — view, respond to, and resolve help tickets
